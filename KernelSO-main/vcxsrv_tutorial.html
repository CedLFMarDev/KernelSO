🚀 Como Abrir VcXsrv

1 Clique no Menu Iniciar

Procure o Menu Iniciar do Windows no canto inferior esquerdo da tela.

💡 Dica: Você pode também pressionar a tecla ⊞ Windows no seu teclado

2 Procure por "XLaunch"

Digite XLaunch na caixa de busca que aparece.

🔍 A caixa de busca aparece automaticamente quando você abre o Menu Iniciar

3 Clique no Resultado

Procure por XLaunch nos resultados de busca e clique nele.

✅ O ícone é geralmente uma janela com uma logo de servidor X

4 Configure XLaunch

Uma janela de configuração vai abrir. Siga as opções abaixo:

📋 Página 1:
• Selecione: Multiple windows
• Click: Next

📋 Página 2:
• Deixe como padrão (Display number: -1)
• Click: Next

📋 Página 3:
• Deixe todas as opções padrão
• Click: Next

📋 Página 4:
• Marque: ✓ Disable access control
• Click: Finish

5 Abra o Terminal PowerShell

Procure por PowerShell no Menu Iniciar e clique nele.

6 Execute o Kernel

No terminal, copie e cole o comando abaixo:

wsl -d Ubuntu -u root -- bash -lc "cd /mnt/c/Users/marco/Downloads/KernelSO-main/KernelSO-main && DISPLAY=:0 make run"
✨ Pronto!
A janela do QEMU com seu kernel deve abrir com o texto em VERDE sobre fundo AZUL!
